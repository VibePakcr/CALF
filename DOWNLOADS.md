## Free Repository Navigator / 무료 통합 탐색 확장팩

Explore Local Git, GitHub and GitLab through one map and code/Diff inspector. This optional standalone preview requires Python 3.10+, Git 2.43+ and a modern browser; CALF core, SDK and models are not required.

Local Git·GitHub·GitLab을 같은 지도와 코드·Diff 상세 보기로 탐색합니다. 별도 무료 프리뷰이며 Python 3.10 이상·Git 2.43 이상·최신 브라우저가 필요합니다. CALF core·SDK·모델은 요구하지 않습니다.
