# 기존 로컬 모델 서버 연결 — 미리보기

[English](LOCAL_MODELS.md)

선택형 Rust 연결 기능으로 **이미 설치된 Ollama** 또는 **MLX-LM 등
OpenAI 호환 채팅 서버**를 사용할 수 있습니다. CALF의 제어·지식 조회·검사는
계속 로컬 CPU에서 작동하며 모델을 필요로 하지 않습니다. 추론 자원은 모델
서버가 별도로 사용합니다.

Workbench의 **AI connection → Existing local model server**에서 서버 유형,
주소와 서버 목록에 표시된 정확한 모델 이름을 입력합니다. Ollama의 일반적인
주소는 `http://127.0.0.1:11434`입니다. 채팅 서버는 실제 포트와 `/v1` 경로를
사용합니다. 예: `http://127.0.0.1:8080/v1`.

**Verify connection**은 모델 목록만 조회합니다. 응답 생성·모델 다운로드·서버
시작은 하지 않습니다. 명시적인 HTTP 루프백 주소(`127.0.0.1`, `::1`)만
허용하고, 해당 연결에서는 프록시와 리다이렉트를 사용하지 않습니다. 시스템의
프록시나 런타임 설정은 바꾸지 않습니다. 서버는 사용자가 별도로 실행하며,
연결 실패 시 클라우드로 자동 전환하지 않습니다.

API 연결은 기존 `helper`·`executable`·`account` 필드에
`kind: "local"`, `protocol: "ollama"` 또는 `"openai-chat"`,
`endpoint`, `model`, `outputTokens`를 지정합니다. 출력 한도는 128–2048이며
Workbench는 512를 사용합니다. 새 작업은 연결과 실행 파일을 고정해 보존하고,
기존 작업의 설정은 유지합니다. 로컬 추론은 무거운 작업으로 분류합니다.

응답은 기존 계획·검토 계약에 맞는 완전한 JSON이어야 합니다. 잘린 응답,
중복 키, 도구 호출, 형식이 맞지 않는 결과는 유효한 계획으로 받아들이지
않습니다. 변경 범위·보호 파일·등록 검사·별도 검토·완료 기준은 그대로입니다.
작업 입력이 모델의 문맥 한도를 넘으면 실패할 수 있습니다. 이를 맞추려고
증거를 몰래 잘라내거나 검사를 완화하지 않습니다.

요청 제한 시간은 150초입니다. Ollama 요청은 문맥 4,096토큰과
`keep_alive: 0`을 사용합니다. 모델의 메모리 사용량은 CALF와 별개입니다.
CALF를 중단해도 다른 서버의 추론까지 취소됐다고 보장할 수는 없습니다.
결과가 불명확하면 다시 제출하기 전에 서버 상태부터 확인해야 합니다.

## 이번 배포에서 확인한 범위

MacBook Air M5 16GB의 실제 Codex 연결 작업은 지식 선택 지문을 유지한 채
등록 검사·별도 검토와 독립적으로 재실행한 테스트 3개를 통과했습니다.
해당 작업의 통과이며, 모든 지식의 정확성이나 지식 활용 효과를 입증한 것은
아닙니다.

설치된 Qwen 7B Ollama 모델은 로드 중 스왑이 급증해 CALF가 시도를 중단했습니다.
Qwen 7B MLX 모델은 기존 MLX 0.32.4 / MLX-LM 0.32.2로 로드됐지만, 메모리
경고가 20초 지속돼 기존 가드가 별도 시험 서버를 종료했습니다. 두 시험 모두
작업 완료에는 도달하지 못했습니다. 실패 기록과 자원 제한은 유지했습니다.
따라서 이번 배포에서 **MLX·Ollama의 작업 완료까지 검증됐다고 안내하지 않습니다.**
모델 목록 연결 및 모델을 사용하지 않는 통신 검수와 구분합니다. 새 모델은
다운로드하지 않았습니다.

Windows·Linux의 지식 조회·실행 흐름 검증은 그 호스트에서 MLX나 실제 로컬
추론까지 검증했다는 뜻이 아닙니다. 이 연결은 미리보기 기능입니다. 이번 배포를 설치해도 기존 서버나 모델 설정을
자동으로 바꾸지 않습니다.
